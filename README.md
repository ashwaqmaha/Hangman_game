# Hangman Game

This command-line-based Hangman game is a fun and interactive word-guessing game designed to test your vocabulary and problem-solving skills. Built in Python, this project showcases expertise in user interaction, condition handling, and game logic implementation.

## Features 

- **Guess Letters**: Enter one letter at a time to guess the hidden word.
- **Strikes and Attempts**: Incorrect guesses result in strikes, and players are allowed a maximum of 6 attempts.
- **Mystery Word Display**: The hidden word updates with each correct guess, showing the correctly guessed letters in their respective positions.
- **Game Progress Visualization**: The hangman drawing progressively appears as incorrect guesses accumulate.
- **Game Duration**: The game tracks how long it took to either win or lose and displays it at the end of the game.
- **Exit Early**: Players can exit the game by typing "exit".

## Technologies Used 

- **Python**: Core programming language for game logic and user interaction.
